# Distributed Applications

Welcome to the **Distributed-applications** repository! This project serves as a dedicated workspace for practical lab sessions and assignments related to distributed systems and architectures.

## Overview

This repository chronicles the development and exploration of distributed application architectures. It is segmented into various sessions (Séances), each focusing on different principles, algorithms, and practical implementations of distributed systems. The primary language used throughout these sessions is Python, chosen for its robust networking and concurrency libraries.

## Key Topics Covered

- **Distributed Systems Fundamentals**: Hands-on exploration of client-server models, peer-to-peer networking, and message passing.
- **Concurrency & Multithreading**: Utilizing Python to handle multiple networked processes simultaneously.
- **Network Programming**: Building socket-based applications to demonstrate inter-process communication across networks.

## Repository Structure

- `Séance-5/`: Contains lab work and exercises from Session 5.
- `Séance 6/`: Contains lab work and exercises from Session 6.
- `Séance 7/`: Contains lab work and exercises from Session 7.

## Usage

To run the examples in this repository, you will need a standard Python 3.x environment. Each `Séance` directory contains its own specific scripts which can be executed directly from the command line:

```bash
python <script_name>.py
```
